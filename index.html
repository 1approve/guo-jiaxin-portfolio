02 / WORKFLOW

从文字意图到
稳定画面。

生成不是终点。把每一阶段留下的判断，变成下一阶段可复用的约束。

  1. 01

    拆解叙事

    明确人物行动、情绪节奏与镜头衔接，把文本转译为可执行的镜头任务。

    SCRIPT → SHOTS
  2. 02

    建立规范

    固定角色、服饰、色彩、空间与核心道具，先定义世界，再开始批量生成。

    WORLD → RULES
  3. 03

    生成与返修

    组合参考图、首尾帧和提示词，筛选版本并逐镜解决重复、错位、跳变与漂移。

    GENERATE → REFINE
  4. 04

    剪辑交付

    以叙事为准重组素材，完成节奏、字幕、声音、合成与最终校对。

    EDIT → DELIVER
